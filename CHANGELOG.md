# Changelog

All notable changes to Sift are listed here, newest first.

## 1.0.0-beta (2026-11-26)

- Added logs.
- Linux (x64): `.deb` package (Debian / Ubuntu), `.rpm` package (Fedora / RHEL) and AppImage. Windows and macOS builds are not out yet.

## 0.9.0-alpha (2026-11-21)

- First public build.
- Windows (x64): `.exe` installer, `.msi` package and portable ZIP.
- Linux (x64): `.deb` package (Debian / Ubuntu), `.rpm` package (Fedora / RHEL) and AppImage.
- macOS (Apple Silicon): `.dmg` disk image.
